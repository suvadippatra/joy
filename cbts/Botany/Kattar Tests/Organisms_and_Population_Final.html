❓ CBT Setter Guide

Advanced Features & Best Practices

  1. AI Prompt Injection: Click 🤖 Prompt, copy the prompt text, and paste it into Gemini/ChatGPT alongside your question PDF. Then copy the generated `.cbt` code and paste it into 📌 Import.
  2. Image, GIF & SVG Support: Upload standard images (JPG, PNG, WEBP) as well as animated GIFs and vector SVGs directly from the same upload button. When uploading SVG or GIF, choose ⚡ Use Original in the dialog to preserve vector scalability and animations without lossy recompression.
  3. Memory Protection (20s VRAM Flush): To prevent mobile browsers from freezing, images load behind a `🖼️ View Image` button. When clicked, the image renders for 20 seconds before auto-flushing from GPU memory. You can reveal all images at once from the ⋮ menu.
  4. Typography: Use **bold**, *italic*, and __underline__ directly in text boxes. Scientific names (e.g. *Mangifera indica*) must be italicized using single asterisks.
  5. Image Auto-Detection: If the AI cannot read a diagram, it will output `[IMAGE]`. The system automatically catches this, clears the text, and spawns a glowing red 🚨 UPLOAD MISSING IMAGE button.
  6. Adaptive Resizer & Fast-Scroll Rail: On tablets or phones, drag the thin `⋮` handle smoothly with fingers or mouse to adjust split-screen view. Use the right elevator scrubber to instantly navigate long pages.
  7. Syncing & Compiling: Always click 📌 Import -> 🔄 Sync CBT Code to generate a local backup. When complete, click 🚀 Compile Final HTML to generate your fully standalone, offline exam file.

Writing Mathematics & Formatting (LaTeX, KaTeX, MathML, HTML)

  • LaTeX Formulas: Wrap inline equations in single dollar signs ($E = mc^2$) and display equations in double dollar signs ($$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$).
  • Multiplication Symbol Rule: NEVER use the asterisk * for multiplication in math (e.g., $2 * 3$ collides with Markdown italics). Always write \times (for $\times$) or \cdot (for $\cdot$).
  • HTML Mode Symbols: When typing directly in HTML mode, do not use LaTeX backslashes. Use standard Unicode (π, α, β, θ, ±, √, ×, ÷, →) and native HTML tags: <sup>2</sup> for exponents and <sub>2</sub> for subscripts.
  • Compilation Engine Options:
    • Native MathML: Lightweight offline math rendered directly by the browser engine.
    • KaTeX (Online): Publication-grade typography requiring an internet connection.
    • Pure HTML Fallback: Converts math to lightweight italicized HTML with sub/sup scripts for maximum offline compatibility.

Sections, Marking, and Max Attempts

  • Renaming Sections: Click inside the Section Name cell in the table to rename it. Press Enter or click outside (blur) to save without freezing the interface.
  • Mark (+) & Neg (-): Set correct answer score and penalty. NAT questions automatically override Negative penalty to 0.
  • Max Attempts (Max Att): Enforces NTA/GATE style limits. If a candidate attempts 12 questions in a section with a Max Att of 10, only their first 10 attempts in numerical order will be evaluated. Set to 0 for unlimited attempts.

Audio, Custom Rules, and Scientific Constants

  • Dynamic Rules: Rules automatically adapt to your chosen Duration and Timer Mode (Stopwatch vs Countdown). Custom rules can be added line-by-line under Advanced Settings.
  • Audio Base64: Attach background ambient audio, exam start bells, or submit audio using valid Data URIs (data:audio/mp3;base64,...).
  • Reference Constants: Click "Load Default Scientific Constants" in the modal to instantly import universal physical constants ($c, h, G, e$).

Memory Management & Preventing Crashes

  • Memory Tracker: Check the live Memory Load bar inside the `⋮` menu. If the bar reaches orange or red, your browser tab has accumulated heavy DOM nodes.
  • Clearing Memory: Always click 🔄 Sync CBT Code first to download or copy your backup, then click 🧹 Clear Workspace to instantly release browser RAM.

অ্যাডভান্সড ফিচার ও সেরা কার্যপ্রণালী

  1. AI Prompt ব্যবহার: 🤖 Prompt বাটনে ক্লিক করে প্রম্পট কপি করুন এবং Gemini/ChatGPT-তে প্রশ্নপত্রের PDF-এর সাথে দিন। AI যে `.cbt` কোড দেবে, তা 📌 Import-এ পেস্ট করে ইনপুট নিন।
  2. ছবি, GIF ও SVG সাপোর্ট: সাধারণ ছবি (JPG, PNG) ছাড়াও একই বাটন দিয়ে অ্যানিমেটেড GIF এবং ভেক্টর SVG সরাসরি আপলোড করা যাবে। ডায়ালগে ⚡ Use Original ক্লিক করলে কোয়ালিটি ও অ্যানিমেশন অক্ষুণ্ণ থাকবে।
  3. মেমরি সুরক্ষা (20s VRAM Flush): মোবাইল ব্রাউজারের ক্র্যাশ রুখতে ছবিগুলো সরাসরি লোড না হয়ে `🖼️ View Image` বাটন হিসেবে থাকে। ক্লিক করলে ২০ সেকেন্ডের জন্য ছবি দেখা যাবে, এরপর নিজে থেকেই মেমরি থেকে মুছে যাবে। ⋮ মেনু থেকে সব ছবি একসাথে দেখা যায়।
  4. টাইপোগ্রাফি: লেখা বোল্ড বা ইটালিক করতে **bold**, *italic*, এবং __underline__ ব্যবহার করুন। বৈজ্ঞানিক নাম (যেমন *Mangifera indica*) অবশ্যই অ্যাস্টেরিস্ক দিয়ে ইটালিক করবেন।
  5. অটো-ইমেজ ডিটেকশন: AI যদি কোনো ডায়াগ্রাম পড়তে না পারে তবে `[IMAGE]` লেখে। আমাদের সিস্টেম তা নিজে থেকেই ধরে ফেলে এবং লাল রঙের 🚨 UPLOAD MISSING IMAGE বাটন বানিয়ে দেয়।
  6. মোবাইল ও ট্যাবলেট রিসাইজার: ফোন বা ট্যাবলেটে `⋮` হ্যান্ডেলটি আঙুল বা মাউস দিয়ে টেনে এডিটর ও লাইভ প্রিভিউয়ের সাইজ নিজের মতো ঠিক করে নিন। সাইড স্ক্রাবার দিয়ে পেজ দ্রুত স্ক্রোল করুন।
  7. সিঙ্ক ও কম্পাইল: কাজ চলাকালীন 📌 Import -> 🔄 Sync CBT Code ক্লিক করে ব্যাকআপ রাখুন। সবশেষে 🚀 Compile Final HTML-এ ক্লিক করে আপনার সম্পূর্ণ অফলাইন পরীক্ষার ফাইলটি ডাউনলোড করুন।

গণিত ও ফরম্যাটিং (LaTeX, KaTeX, MathML, HTML)

  • LaTeX সমীকরণ: সাধারণ সূত্রের জন্য সিঙ্গেল ডলার ($E = mc^2$) এবং ডিসপ্লে ব্লকের জন্য ডাবল ডলার ($$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$) ব্যবহার করুন।
  • গুণের নিয়ম (Multiplication): গণিতের ভেতরে কখনোই স্টার * ব্যবহার করবেন না (যেমন $2 * 3$ দিলে ইটালিক কোডের সাথে সংঘর্ষ হবে)। সবসময় \times ($2 \times 3$) অথবা \cdot ব্যবহার করুন।
  • HTML মোড প্রতীক: HTML মোডে সরাসরি লেখার সময় ব্যাকস্ল্যাশ ছাড়া ইউনিকোড প্রতীক (π, α, β, θ, ±, √, ×, ÷, →) এবং পাওয়ার/সাবস্ক্রিপ্টের জন্য <sup>2</sup> ও <sub>2</sub> ট্যাগ দিন।
  • ইঞ্জিন নির্বাচন: MathML অফলাইন ব্রাউজার রেন্ডারিংয়ের জন্য সেরা, KaTeX অনলাইন সর্বোচ্চ মান দেয়, এবং HTML Fallback দুর্বল ডিভাইসের জন্য উপযোগী।

সেকশন, মার্কিং এবং সর্বোচ্চ প্রচেষ্টা (Max Att)

  • সেকশনের নাম পরিবর্তন: ছকে সেকশনের নামের উপর ক্লিক করে নাম লিখুন এবং বাইরে ক্লিক করুন বা Enter চাপুন।
  • মার্ক (+ ও -): সঠিক উত্তরের জন্য প্রাপ্ত নম্বর এবং ভুল উত্তরের জন্য নেগেটিভ মার্ক দিন। NAT প্রশ্নে নেগেটিভ মার্ক সবসময় ০ থাকবে।
  • Max Attempts (সর্বোচ্চ প্রচেষ্টা): পরীক্ষার্থী একটি সেকশন থেকে সর্বোচ্চ কয়টি প্রশ্নের মূল্যায়ন করাতে পারবেন তা নির্ধারণ করে (যেমন ১৫টির মধ্যে ১০টি)। ০ দিলে সীমাহীন।

অডিও, রুলস এবং বৈজ্ঞানিক ধ্রুবক (Constants)

  • রুলস: পরীক্ষার সময়কাল এবং টাইমার মোড (Stopwatch/Countdown)-এর ওপর ভিত্তি করে রুলস নিজে থেকেই আপডেট হয়।
  • অডিও Base64: ব্যাকগ্রাউন্ড মিউজিক বা স্টার্ট/সাবমিট সাউন্ডের জন্য Data URI Base64 কোড দিন।
  • কনস্ট্যান্টস: "Load Default Scientific Constants" বাটনে এক ক্লিকেই পদার্থবিজ্ঞানের ধ্রুবকগুলো লোড করুন।

মেমরি সুরক্ষা ও ব্রাউজার পারফরম্যান্স

  • মেমরি মনিটর: ত্রি-বিন্দু (⋮) মেনুতে রিয়েল-টাইম মেমরি লোড খেয়াল রাখুন।
  • মেমরি খালি করা: প্রথমে 🔄 Sync CBT Code ক্লিক করে ব্যাকআপ ডাউনলোড করুন, তারপর 🧹 Clear Workspace দিয়ে ব্রাউজারের RAM খালি করে নিন।
